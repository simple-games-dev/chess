# Tempo

Chess, with the clock running.

## 🎮 Play it [here](https://simple-games-dev.github.io/chess/)

## Features

- ♟️ Standard chess
- ⏱️ Multiple time controls
- ⚙️ Custom time + increment
- 💻 Play locally on the same device
- 🌐 Online games with friends
- 🚀 Premove support
- 🎨 Board themes
- ➕ Add time to your opponent's clock
- 🏳️ Resign at any time
- 🤝 Automatic draw detection

Pick a time control, start a game, and play.
